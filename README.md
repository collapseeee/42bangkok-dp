# 42Bangkok Discovery Piscine  

## 🌊 Thrown into the Deep End

This repo holds everything I worked on during the **42Bangkok Discovery Piscine**—a crazy, intense, and honestly amazing coding camp. The experience was like getting pushed into a pool and figuring out how to swim… fast. **"Do it or die"** might sound extreme, but it’s pretty accurate.

## 📂 What’s Inside?  
Here’s what I built, broke, and eventually figured out:  
- **Shell Scripting** – Learning to control the command line like a wizard.  
- **HTML, CSS, JavaScript** – Making the web not just functional, but beautiful.  (missing some exercise from JavaScript part.)
- **Rush Project** – The best part! I teamed up with a friend to build a website introducing both of us. It was pure chaos, but we made it work.  

## 🧠 What I Learned  
- **How to learn on my own** – No hand-holding, just problem-solving.  
- **How to work with others** – Coding is fun, but coding *together* is a whole different level.  
- **How to build stuff that actually works** – The web is wild, and I got to create something real.  

## ❤️ Final Thoughts  
42Bangkok wasn’t just a camp—it was a whole experience. I walked in not knowing what to expect and left with new skills, new memories, and new friends who love tech as much as I do.
